## <a name="bot">О боте</a>

<p>Вашему вниманию представляется зарплатный телеграм-бот</p>
<p>Бот написан на языке программирования <b>Python</b> (v3.9.13) с использованием асинхронной библиотеки для создания ботов <b>aiogram</b>
  
<p><b>У бота есть несколько основных задач:</b> </p>
<ul>
  <li>получать мое расписание и сопутсвующие данные (учеников, группы и тд) по API из CRM</li>
  <li>Формировать расписание и с помощью AsyncIOScheduler после каждого урока собирать информацию и рассчитывать зарплату</li>
  <li>Сохранять зарплату в excel таблицу</li>
</ul>

<p><b>У бота есть несколько дополнительных задач:</b> </p>
<ul>
  <li>сохранять незапланированные уроки</li>
  <li>сохранять отработки</li>
  <li>выводить расписание на день</li>
</ul>


## <a name="install">Как установить</a>

<p>Клонировать репозиторий</p>

`git clone https://github.com/Mhch497/SalaryTGBot.git`

<p>Перейти в папку с ботом</p>

`cd .\SalaryTGBot\`

<p>Запустить бота</p>

`python main.py`

<p>P.S. Важно учитывать, что секреты прописаны в перменных окружения</p>
<p>P.P.S. В текущее время бот не хостится за ненадобностью</p>
